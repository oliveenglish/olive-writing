# 올리브 라이팅

초등 be동사 문장부터 B1 에세이까지, 유닛별 연습 · 복습 · 점검 · 첨삭을 하는 글쓰기 학습 사이트.

- 사이트 코드: Next.js (이 폴더)
- 데이터 · 로그인 · 사진: Supabase
- 사이트 올리기: Vercel (GitHub과 연결)
- AI 첨삭 초안 (선택): Anthropic API

---

## 처음 한 번만 하는 설치 (약 30분)

### 1. Supabase 프로젝트 만들기
1. supabase.com → New project (지역: Northeast Asia (Seoul))
2. 왼쪽 **SQL Editor** → `supabase/schema.sql` 파일 내용을 통째로 붙여 넣고 **Run**
3. **Project Settings → API** 에서 세 가지를 복사해 둡니다.
   - Project URL
   - anon public key
   - service_role key (**절대 남에게 보여 주지 마세요**)

### 2. GitHub에 올리기
1. github.com → New repository → 이름 `olive-writing` → **Private** 으로 만들기
2. 이 폴더 전체를 올립니다. (GitHub Desktop 또는 웹의 "uploading an existing file")
   - `.env` 파일은 올리지 않아요. (`.gitignore`에 들어 있어요)

### 3. Vercel에 연결
1. vercel.com → Add New → Project → GitHub의 `olive-writing` 선택
2. **Environment Variables** 에 아래를 넣고 Deploy
   | 이름 | 값 |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | Supabase Project URL |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon public key |
   | `SUPABASE_SERVICE_ROLE_KEY` | service_role key |
   | `TEACHER_EMAILS` | 쌤 이메일 (여러 개면 쉼표로) |
   | `ANTHROPIC_API_KEY` | (선택) AI 첨삭 초안을 쓸 때 |
   | `ANTHROPIC_MODEL` | (선택) 기본 `claude-sonnet-5-5` |

### 4. 쌤 계정 · 문항 넣기
1. 사이트 주소 → **쌤 로그인 → 쌤 계정 처음 만들기** (TEACHER_EMAILS 에 넣은 이메일)
2. **반 전체** 화면 오른쪽 위 **반 코드** 칸에서 새 반 만들기 → `OLIVE-1234` 같은 코드가 생겨요
3. **문항 DB** → `올리브라이팅_문항DB.xlsx` 올리기 → 미리 보기 확인 → **반영하기**
4. 학생에게 사이트 주소 + 반 코드를 알려 주면, 학생이 **반 코드로 시작하기**에서 아이디 · PIN을 만들어요

## 매일 쓰는 흐름

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 학생 | 홈 · 오늘의 미션 | 새 유닛 이어 하기 → 복습 → 첨삭 확인 → 금요일 주간 점검 |
| 학생 | 유닛 | 단어 → 설명 카드 → 단어 배열 → 틀린 문장 → 한글→영어 → 대답 쓰기(쌤 첨삭) → 확인 테스트 |
| 쌤 | 반 전체 | 학생별 위치 · 정답률 · 약점 · 알림(2번 연속 미통과 · 미접속) |
| 쌤 | 첨삭 · 채점 | 사진 위에 빨간 펜 · 고친 글 · 오류 찍기 · 한마디 → 학생 화면에 원본/첨삭본 나란히 |
| 쌤 | 학생 상세 | 시작 유닛 바꾸기 · 메모 · PIN 다시 정하기 · 주간 점검 미루기/건너뛰기 · 학부모 리포트 |
| 쌤 | 추가 과제 | 학생별 약점 자동 · 유닛 고르기 · 글쓰기 |
| 쌤 | 문항 DB | 엑셀 올리기 → 검사 → 반영 |

### 정해 둔 규칙 (나중에 바꿀 수 있어요)
- 확인 테스트: 유닛 시트의 "통과 기준" 숫자(기본 8문제 중 7개) 이상이면 통과
  - 통과선보다 1~2개 모자라면 설명 카드부터 다시 → 재시험
  - 그보다 낮으면 연습부터 다시
  - 2번 연속 미통과 → 쌤 대시보드 알림
- 틀린 오류 코드 → 1 · 3 · 7일 뒤 복습 미션
- 같은 오류 3번 이상 (30일) → 약점
- 주간 점검: 그 주에 공부한 유닛에서 10문제 (배열 3 · 고치기 3 · 한글→영어 3 · 대답 1), 금요일부터 열림
- 최종 점검: 한 단계의 유닛을 모두 통과하면 열림. 파트 1 문법 20문제 + 파트 2 글쓰기(점검 소재 중 선택) → 쌤이 기준표 채점 후 통과/보충 결정
- AI 첨삭: 키가 있으면 제출할 때 AI가 초안을 만들어 둬요. 쌤 화면에서 "AI 바로 보내기"를 켜면 쌤 확인 없이 학생에게 가요 (최종 점검은 항상 쌤 확인)
- AI는 학생이 이미 배운 오류 코드만 써요 (배운 것만 채점)

## 문제가 생기면

| 상황 | 할 일 |
|---|---|
| 학생이 PIN을 잊음 | 쌤 화면 → 학생 상세 → PIN 다시 정하기 |
| 화면에 오류가 남 | 화면 캡처 + Vercel → 프로젝트 → **Logs** 의 빨간 줄을 캡처해서 Claude에게 |
| 고친 뒤 더 이상해짐 | Vercel → Deployments → 이전 버전 ⋯ → **Promote to Production** (되돌리기) |
| 문항이 이상함 | 엑셀을 고쳐서 문항 DB에 다시 올리기 |
