# 올리브 라이팅

be동사 문장을 만들 수 있는 학생부터 에세이까지, 워크시트와 함께 쓰는 글쓰기 학습 사이트 (앱 단어 · 문장 연습 + 워크시트 사진 제출 + 쌤 첨삭).

- 사이트 코드: Next.js (이 폴더)
- 데이터 · 로그인 · 사진: Supabase
- 사이트 올리기: Vercel (GitHub과 연결)
- AI 첨삭 초안 (선택): Anthropic API

---

## 처음 한 번만 하는 설치 (약 30분)

### 1. Supabase 프로젝트 만들기
1. supabase.com → New project (지역: Northeast Asia (Seoul))
2. 왼쪽 **SQL Editor** → `supabase/schema.sql` 파일 내용을 통째로 붙여 넣고 **Run**
3. **Project Settings → API** 에서 세 가지를 복사해 둡니다.
   - Project URL
   - anon public key
   - service_role key (**절대 남에게 보여 주지 마세요**)

### 2. GitHub에 올리기
1. github.com → New repository → 이름 `olive-writing` → **Private** 으로 만들기
2. 이 폴더 전체를 올립니다. (GitHub Desktop 또는 웹의 "uploading an existing file")
   - `.env` 파일은 올리지 않아요. (`.gitignore`에 들어 있어요)

### 3. Vercel에 연결
1. vercel.com → Add New → Project → GitHub의 `olive-writing` 선택
2. **Environment Variables** 에 아래를 넣고 Deploy
   | 이름 | 값 |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | Supabase Project URL |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon public key |
   | `SUPABASE_SERVICE_ROLE_KEY` | service_role key |
   | `TEACHER_EMAILS` | 쌤 이메일 (여러 개면 쉼표로) |
   | `ANTHROPIC_API_KEY` | (선택) AI 첨삭 초안을 쓸 때 |
   | `ANTHROPIC_MODEL` | (선택) 기본 `claude-sonnet-5-5` |

### 4. 쌤 계정 · 문항 넣기
1. 사이트 주소 → **쌤 로그인 → 쌤 계정 처음 만들기** (TEACHER_EMAILS 에 넣은 이메일)
2. **반 전체** 화면 오른쪽 위 **반 코드** 칸에서 새 반 만들기 → `OLIVE-1234` 같은 코드가 생겨요
3. **문항 DB** → `올리브라이팅_문항DB.xlsx` 올리기 → 미리 보기 확인 → **반영하기** (단어 엑셀도 같은 곳에)
4. **반 전체 → 학생 계정 만들기**에서 쌤이 아이디 · PIN을 만들어 주고, 학생 상세에서 수업 요일을 골라요

## 매일 쓰는 흐름

학생 유닛 화면 = 워크시트 맨 앞 **'이번 주 할 일'**과 같은 체크리스트예요. (수업이 화 · 금이면 월~토)

| 요일 | 할 일 | 어디서 |
|---|---|---|
| 월 | 📱 앱 단어 학습 (듣고 익히기 → 뜻 맞히기 → 듣고 고르기 → 철자 쓰기) → ✏️ 1~2쪽 단어 쓰기 → 📷 | 앱 · 워크시트 |
| 화 | 📱 Warming Up Test (단어 10문제) → 👩‍🏫 수업 | 앱 · 수업 |
| 수 | 📱 앱 문장 연습 (설명 다시 보기 → 단어 배열 → 틀린 표현 → 한글 → 영어) → ✏️ 6~7쪽 → 📷 | 앱 · 워크시트 |
| 목 | ✏️ 8쪽 Organizer → 📷 | 워크시트 |
| 금 | 👩‍🏫 수업 → ✏️ 9쪽 내 글 쓰기 → 📷 (쌤 빨간 펜 첨삭) | 수업 · 워크시트 |
| 토 | 👀 첨삭 확인 → ✏️ 10쪽 다시 쓰기 → 📷 → 📱 확인 테스트 | 앱 · 워크시트 |

- 칸은 **전부 열려 있어요** (순서대로 안 해도 돼요). 📱 앱 활동 · 📷 사진은 하면 저절로 체크, 👩‍🏫 수업은 학생이 직접 체크해요.
- 요일은 학생마다 **쌤이 학생 상세 → 수업 요일**에서 두 개 골라요. (기본 화 · 금)
- 확인 테스트를 통과하면 다음 유닛이 열려요.

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 쌤 | 반 전체 | 학생별 위치 · 이번 주 할 일 몇 개 했는지 · Warming Up 점수 · 알림 |
| 쌤 | 첨삭 · 채점 → ✏️ 첨삭 대기 | 9쪽 내 글 · 주간 점검 · 쌤 과제 글: 사진 위에 빨간 펜 → 학생 화면에 원본/첨삭본 나란히 |
| 쌤 | 첨삭 · 채점 → 📷 사진 확인 | 1~2 · 6~7 · 8 · 10쪽 사진: ✓ 확인 / ↺ 다시 써 와요 (10쪽은 9쪽 첨삭본과 나란히) |
| 쌤 | 학생 상세 | 수업 요일 · 이번 주 할 일 · 시작 유닛 · 메모 · PIN · 주간 점검 미루기/건너뛰기 · 학부모 리포트 |
| 쌤 | 문항 DB | 엑셀 올리기 → 검사 → 반영 (단어 시트만 따로 올려도 돼요) |

### 단어 시트 (유닛마다 익힐 단어 20개)
칸: **유닛 · 순서 · 단어 · 품사 · 뜻 · 예문 · 예문 뜻** (묶음은 선택). 시트 이름은 '단어' 또는 '어휘'.
같은 유닛 단어를 다시 올리면 새 목록으로 바뀌어요.

### 정해 둔 규칙 (나중에 바꿀 수 있어요)
- 시작은 Basic(B-Unit)부터. PREP(P-Unit)은 쓰지 않아요 — 엑셀에 있어도 건너뛰어요.
- 확인 테스트: 8문제 중 6개(유닛 시트 "통과 기준") 이상이면 통과. 못 넘으면 틀린 것과 비슷한 문제 몇 개 → 확인 테스트만 다시. 2번 연속 미통과 → 쌤 대시보드 알림
- Warming Up Test: 통과 기준 없음, 점수만 쌤에게 (다시 보면 새 점수)
- 같은 오류 3번 이상 (30일) → 약점
- 주간 점검: 그 주에 확인 테스트를 본 유닛에서 10문제, 금요일부터 열림. 3개까지 틀리면 인정
- AI 첨삭 초안: 9쪽 사진 · 주간 점검 · 과제 글에만 (확인만 하는 사진은 AI를 안 돌려요). 결과는 항상 쌤이 확인한 뒤에 보내요

## 문제가 생기면

| 상황 | 할 일 |
|---|---|
| 학생이 PIN을 잊음 | 쌤 화면 → 학생 상세 → PIN 다시 정하기 |
| 화면에 오류가 남 | 화면 캡처 + Vercel → 프로젝트 → **Logs** 의 빨간 줄을 캡처해서 Claude에게 |
| 고친 뒤 더 이상해짐 | Vercel → Deployments → 이전 버전 ⋯ → **Promote to Production** (되돌리기) |
| 문항이 이상함 | 엑셀을 고쳐서 문항 DB에 다시 올리기 |
