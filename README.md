# 올리브 브릿지 라이팅

단어 → 문장 → 글쓰기를 매주 한 유닛씩. 학생은 앱에서 단어 · 문장을 연습하고, 워크북 숙제를 사진으로 인증하고, 쌤은 빨간 펜으로 첨삭해요.

- 사이트 코드: Next.js (이 폴더) · 데이터 · 로그인 · 사진: Supabase · 사이트 올리기: Vercel
- **단어 · 예문은 `data` 폴더의 엑셀**에서 읽어요 (DB에 올리지 않아요)

## 이번 주 할 일 (모든 학생 같아요)

| 요일 | 단계 | 어디서 |
|---|---|---|
| 월 | ① 앱 단어 학습 — 10개씩 Set 1 · Set 2, 세트마다 플래시 카드 · 매칭 게임 · 단어 고르기 · 뜻 고르기 | 앱 |
| 월 | ② 워크북 단어 학습 인증 — 사진 | 워크북 → 앱 |
| 화 | ③ 수업 참석 — 학생이 체크 | 수업 |
| 수 | ④ 앱 문장 연습 — 예문 10개씩, 듣고 쉐도잉 · 덩어리 배열 | 앱 |
| 수 | ⑤ 쌤 숙제 인증 — 사진 → **쌤 빨간 펜 첨삭** | 워크북 → 앱 |
| 목 | ⑥ 수업 참석 — 학생이 체크 | 수업 |
| 금 | ⑦ 첨삭 확인 · 다시 쓰기 인증 — 원본 / 첨삭본 나란히 보고 다시 써서 사진 | 워크북 → 앱 |

- 쌤이 ⑦을 **✓ 확인**하면 그 학생은 다음 유닛으로 넘어가요. (학생 상세에서 유닛을 직접 바꿀 수도 있어요)
- ② · ⑦은 ✓ 확인 / ↺ 다시 써 와요, ⑤는 사진 위에 빨간 펜 + 한마디.
- 틀린 단어 · 문장은 그 활동 끝에 **한 번만** 다시 나와요.
- 수업 요일은 학생마다 쌤이 정해요 (보기용). 할 일 요일은 모두 월~금 같아요.

## 쌤 화면

| 메뉴 | 하는 일 |
|---|---|
| 이번 주 진행 | 학생별 7단계 표 · 학생 계정 만들기 (아이디 · PIN · 시작 유닛 · 수업 요일) |
| 인증 · 첨삭 | ② · ⑦ 확인, ⑤ 빨간 펜 첨삭 |
| 단어 · 예문 엑셀 | 지금 들어간 유닛 · 단어 보기, 엑셀 바꾸는 방법 |

## 단어 · 예문 엑셀 바꾸기

1. GitHub 저장소 → `data` 폴더 → 예전 엑셀 지우기 (파일 누르고 ⋯ → Delete file)
2. `data` 폴더에서 Add file → Upload files → 고친 엑셀 올리기
3. 1~2분 뒤 Vercel이 다시 배포하면 바뀌어요 (배포할 때 `scripts/build-words.mjs`가 엑셀을 읽어요)

- 엑셀 모양: **'유닛별 주제' 시트**(단계 · 유닛 ID · 유닛 문법 · 주제 · 목표 수준) + **'어휘 · 예문' 시트**(유닛 ID · 번호 · 단어 · 표현 · 품사 · 뜻 · 콜로케이션 · 덩어리 · 예문 · 예문 뜻)
- `data` 폴더에는 .xlsx 파일을 **한 개만** 둬요. 엑셀에 문제가 있으면 Vercel 배포가 실패하고 Logs에 이유가 나와요.

## 처음 한 번 (또는 예전 버전에서 바꿀 때)

1. Supabase → SQL Editor → `supabase/schema.sql` 통째로 붙여 넣고 **Run** (예전 DB여도 그대로 실행해도 돼요)
2. Vercel 환경변수: `NEXT_PUBLIC_SUPABASE_URL` · `NEXT_PUBLIC_SUPABASE_ANON_KEY` · `SUPABASE_SERVICE_ROLE_KEY` · `TEACHER_EMAILS`
3. 사이트 → 쌤 로그인 (처음이면 `/teacher-signup`에서 쌤 계정 만들기) → 이번 주 진행 → 학생 계정 만들기

## 문제가 생기면

| 상황 | 할 일 |
|---|---|
| 학생이 PIN을 잊음 | 쌤 화면 → 학생 이름 → PIN 다시 정하기 |
| 화면에 오류 | 화면 캡처 + Vercel → Logs 빨간 줄 캡처해서 Claude에게 |
| 고친 뒤 더 이상해짐 | Vercel → Deployments → 이전 버전 ⋯ → Promote to Production |
